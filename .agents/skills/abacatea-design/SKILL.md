# ABAcaTEA Design System

## Objetivo

Criar uma interface que transmita:

- acolhimento;
- confiança;
- profissionalismo;
- segurança;
- cuidado;
- infância.

O resultado deve parecer uma clínica profissional moderna.

Não deve parecer uma creche ou site de brinquedos.

## Tipografia

Preferir:

- Inter;
- Poppins;
- Nunito Sans.

## Layout

Priorizar:

- bastante espaço em branco;
- hierarquia visual;
- grid;
- cards;
- bordas suaves;
- espaçamento consistente;
- alinhamento.

## Componentes

Componentes semelhantes devem compartilhar estilos.

Evitar criar estilos completamente diferentes para cada seção.

## Animações

Utilizar animações discretas.

Priorizar:

- fade;
- slide leve;
- hover;
- transições suaves.

Nunca utilizar animações exageradas.

## Responsividade

Sempre testar:

- desktop;
- tablet;
- mobile.

Nunca permitir overflow horizontal.

## Imagens

Imagens devem:

- possuir proporções adequadas;
- não ficar deformadas;
- possuir alt text;
- utilizar lazy loading quando apropriado.

## Regra

Antes de criar um componente visual novo,
verificar se existe um componente reutilizável.
