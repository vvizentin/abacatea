# ABAcaTEA

Site institucional da ABAcaTEA, uma clínica multidisciplinar
pediátrica fictícia.

## Projeto acadêmico

Este projeto foi desenvolvido para demonstrar conceitos de:

- Desenvolvimento Web;
- Git;
- GitHub;
- Branches;
- Pull Requests;
- Testes automatizados;
- CI/CD;
- GitHub Actions.

## Tecnologias

- React
- Vite
- JavaScript
- CSS
- Vitest
- React Testing Library
- GitHub Actions

## Funcionalidades

- Apresentação da clínica;
- Especialidades;
- Equipe;
- Diferenciais;
- Depoimentos;
- FAQ;
- Formulário de contato;
- Layout responsivo.

## CI/CD

O projeto utiliza GitHub Actions para executar automaticamente:

- Lint;
- Testes;
- Build.

O pipeline é executado em Pull Requests e alterações na branch
principal.

## Observação

A ABAcaTEA, seus profissionais, contatos, depoimentos e demais
informações apresentadas no projeto são fictícios e utilizados
exclusivamente para fins acadêmicos.
